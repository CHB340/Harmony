Harmony is a React Native app designed for travelers, explorers, and anyone passionate about discovering the world. It allows users to browse user-generated posts about different countries, search by location, and visually explore travel moments shared by the community.

✨ Features

🔍 Search by Country: Instantly filter posts by typing a country name.
🖼️ User Posts: View travel stories with images, captions, usernames, and countries visited.
🧭 Explore Page: Learn fun country facts and see how others connect with different cultures.
💡 Clean UI: Minimalist and mobile-friendly design for seamless browsing.

🔧 Installation

Clone the repository:
git clone https://github.com/yourusername/harmony.git
Navigate to the project folder:
cd harmony
Install dependencies:
npm install
Run the app:
npx expo start
